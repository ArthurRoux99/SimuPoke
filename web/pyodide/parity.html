SimuPoke · preuve de concept

Le moteur Python, dans le navigateur

Cette page charge le paquet simupoke (wheel pure-Python) dans Pyodide (CPython compilé en WebAssembly), monte les données de jeu dans le système de fichiers virtuel, puis exécute le calculateur de dégâts Python testé — sans aucun port JavaScript. Elle vérifie la parité contre des valeurs de référence.
